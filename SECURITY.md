# Безопасность

## Поддерживаемый режим

Пульт предназначен для домашней сети. Внешний доступ поддерживается через [HTTPS-шлюз](./docs/CLOUD.md) с отдельной авторизацией и обратным SSH-туннелем. Страница выдачи кода открывается только на компьютере с OBS. OBS WebSocket и HTTP-порт Windows остаются внутри локальной сети.

В облачном серверном режиме Caddy запрашивает логин и пароль сайта через HTTP Basic Auth поверх HTTPS. После этого пульт запрашивает отдельный код. Подключение к OBS использует пароль WebSocket через SSH-туннель. Файл `deploy/server/.env` содержит код, хеш пароля сайта и пароль OBS в Base64; Base64 не шифрует пароль. Ограничь доступ к файлу и не публикуй его. Постоянный код сохраняется при повторном запуске; защищай его как пароль.

Код пары даёт доступ к управлению сценами и источниками, просмотру кадра, медиа и Spotify. Предоставляй его только тем, кому доверяешь управление OBS. В LAN используется HTTP, на удалённом шлюзе — HTTPS. Перезапуск пульта меняет код при обычном запуске.

Команды требуют точного `Origin` и кода подключения. Пульт ограничивает число одновременно принятых загрузок, очередь действий, размеры запросов и время ожидания HTTP. Скриншоты отдельных источников доступны для включённых слоёв текущей сцены после входа.

Локальная страница подключения доступна доверенным процессам этого компьютера. В модели доступа предполагается, что компьютер с OBS, его локальные приложения и серверный шлюз контролируются оператором.

## Проверки

В ноябре 2026 года исходники HTTP, обработки команд и файлов, видеопотока и Spotify переданы DeepSeek на статический защитный обзор. Подтверждённые замечания по проверке запросов, нагрузке и жизненному циклу потока учтены в коде. На локальном тестовом стенде проверены запросы без кода, пустой и посторонний Origin, форма команды, лимит размера, нормальная команда из браузера и отдельная авторизация через Caddy. Результаты относятся к этим сценариям и конфигурации стенда.

Передай информацию владельцу приватного репозитория. Укажи версию или коммит, конфигурацию доступа, затронутую функцию и ожидаемое поведение. Удали из отчёта пароли, коды пары, личные URL и содержимое программного кадра.
